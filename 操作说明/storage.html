数据位置

音色索引、生成的预览音频、设置、收藏、标签和分类固定保存在程序旁的 Preview，安装版与 Portable 版相同。Windows 位于 SoundPreviewer.exe 同目录；Mac 位于 .app 旁边，不写入 app 内部。程序目录不可写时会明确报错，请将程序放到可写的独立文件夹。

预览与声音参照的文件引用按 Preview 内的相对路径 保存，例如 音频文件.m4a、InitializationBaselines/参照.wav。退出后将程序、Preview 和 Config 一起移动到新位置，已有音频会从新位置读取，后续音频也只生成在新位置的 Preview。升级时会兼容转换旧绝对路径；已有音频及收藏、标签等记录会保留。

预览压缩与旧缓存

新生成的预览默认保存为 AAC-LC 128 kbps 立体声（.m4a），保留模板选择的 44100 / 48000 Hz，不降低采样率。到「音源与设置 → 试听与存储」可切换「新预览保存格式」；需要无损文件时选择 WAV 并保存设置。

已有 WAV 会继续读取和复用，改变保存格式不会强制重做音色。想释放已有缓存占用，在同页点击「压缩已有 WAV」：程序按文件分组压缩、验证采样率与音区长度，并更新全部引用；成功后才移除本库自有的旧 WAV。收藏、标签、分类、确认状态和音色源文件保留。失败或停止时，已成功压缩的项目保留，其余原文件继续可用；外部、共享、无法确认归属的音频不会删除。

播放、空格键重播、波形与三音区定位同时支持新 AAC 和旧 WAV。压缩使用 Windows / macOS 系统编解码器，不需要 Python、FFmpeg 或额外安装音频程序；AAC 的帧补齐信息保存在同一个 M4A 文件中，无需额外配套文件。生成时的加载防错检查仍使用原始无损音频，加载防错声音参照也保留为 WAV。

升级后的程序兼容旧 WAV；旧程序若只支持 WAV，回退时请使用升级前的 Preview 备份。

缺失目录与恢复

目录缺失后会重新建立必要配置：

启动时的目录情况 程序行为
Preview 和 Config 都没有 无可迁入旧库时新建空库与默认配置，可重新添加目录、扫描和生成
只有 Preview 缺失 保留并读取 Config 中的来源配置，可重新扫描、生成预览
只有 Config 缺失 继续读取 Preview 的记录和预览，从现有库设置重建目录配置；分类规则优先读取兼容旧副本，没有时建立默认规则
Preview 和 Config 都存在 继续使用已有记录、配置与有效缓存，不以默认内容覆盖个人文件

若自动定位到的旧库已不存在，会提示并在当前程序旁新建 Preview；手动指定的旧库导入来源不存在时仍会报错。缺失恢复只重建必要默认内容，不会覆盖损坏的已有配置。音色可重新扫描、预览音频可重新生成；未从备份恢复的收藏、标签、反馈和手工分类不会凭空重建。需要这些记录时，请先退出程序并备份当前目录，再手动恢复旧 Preview；个人分类规则需保留或恢复对应 Config 或旧规则副本。

早期版本可能沿用旧用户库和外部音频目录。升级时将这些位置作为迁移来源：先复制数据库、个人记录、分类规则和引用的预览，并校验复制结果，再在程序旁使用。旧数据库与旧音频保留作为回退备份。已有 Preview 会继续使用自己的记录，只将它引用的外部预览和加载防错参照复制归入，不会被另一套旧库覆盖。兼容旧记录不再意味着继续向旧目录生成音频。

备份、清理与旧库导入

你要做什么 操作与结果
查看实际数据位置 「音源与设置 → 试听与存储」查看当前数据库与音频目录，点击「打开 Preview 文件夹」直接打开
释放试听缓存空间 点击「清空预览」；保留音色记录、收藏、反馈、标签和分类，之后可重新生成
导入另一套旧版本记录 点击「导入旧版音色库」，选择含 library.db 的原目录并确认；先复制校验所选库，再备份当前完整 Preview 并切换，两套记录不合并
选择保存位置 数据固定保存在当前程序旁的 Preview；不再提供任意外部音频输出目录
备份 退出应用后完整复制 Preview 与 Config，保留原音色与外部资源

清理只处理本库可确认归属的预览及声音参照。共享、外部或归属不明的文件会保留并提示，所以「清空预览」不代表把整个目录删空。旧库迁入后，先核对新库记录与试听正常，再自行处理原目录。

手动导入先在临时目录复制所选库与引用音频，校验记录和设置可读后，再将当前 Preview 在程序旁原子改名为 Preview-before-import-*（末尾为唯一标识），完整保留这套记录与文件，然后切换到准备好的新库。切换失败且 Preview 空缺时会尽量恢复原名，并显示备份位置；不要删除提示中的备份目录。

较早版本的备份可能仍含原 Preview 的绝对路径。恢复时先退出程序并备份当前 Preview，再把需要恢复的备份目录还原名为 Preview，避免覆盖任何现有数据。旧库中缺失的音频会保留历史来源和缓存记录，活动预览引用归入当前 Preview，方便之后找回原文件或重新生成。

升级与整体移动

升级时先退出程序。推荐在原程序目录直接升级：Windows 安装版运行新安装包；Portable 替换程序文件；Mac 替换 .app。保留 Preview、Config、categories.json、tags.json 与自定义语言文件 可继续读取个人记录、目录配置和有效缓存；这是保留个人数据的建议，不是程序启动的前置条件。安装包不携带个人目录配置，升级或卸载会保留现有文件。导入另一套旧库时，已有 Config/directories.json 继续作为本程序的目录配置。旧版根目录的 JSON 也请保留，供兼容迁移和回退使用。降回旧程序时应使用升级前备份。

Portable 表示免安装。移动程序前先退出并备份，连同 Preview、Config、categories.json、tags.json 和自定义语言文件一起保留；一键准备的私有环境随目录移动，原音色、插件和手选外部 Python 环境的绝对路径仍需核对。程序不提供应用内自动更新，后续版本从 GitHub 下载。

需要整洁的新目录时，先保留旧目录作为备份，将完整新包解压到独立文件夹，再复制旧 Preview、Config、categories.json、tags.json、自定义语言文件和尚未迁移的旧根目录 JSON。启动后核对原记录、试听及插件路径，再处理旧目录。
