# SoundPreviewer

Windows 本地合成器预制音色库，使用 C#、.NET 8 和 WPF 开发。SQLite 保存来源、预览映射、任务状态与个人反馈，浏览试听不需要启动 DAW。基础应用无需第三方 NuGet 包，也不调用云端服务。

当前交付为可运行的首个开发版本。目录扫描、检索、收藏、反馈、播放、任务恢复和独立渲染进程已实现；真实音源的支持范围见 [渲染验证记录](docs/rendering.md)。AI 向量搜索、个人推荐、FXB 银行槽位遍历与 macOS 尚未实现。

## 启动

需要 Windows 10/11、.NET 8 Desktop Runtime；从源码构建还需要 .NET 8 SDK。仓库固定 SDK 8.0.425，允许更新的 .NET 8 功能版本。

双击仓库中的 `Start-SoundPreviewer.cmd`，或使用下面的启动命令。

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-SoundPreviewer.ps1
```

启动脚本将本地数据保存在仓库的 `local-data`，不会提交到 Git。直接打开 `SoundPreviewer.exe` 时，默认数据目录为 `%LOCALAPPDATA%\SoundPreviewer`。可通过 `--data-directory` 指定另一音色库。

## 配置与使用

1. 在「音源与设置」中选择「自动识别（混合音色包）」并添加整个音色包目录，无需按音源拆分子目录。也可明确选择单一音源；已有目录保留原来的指定方式，可选中后点击「自动识别此目录」切换。
2. 在共享的「VSTi 安装目录」中添加插件安装目录并扫描。「已发现音源」保留版本、格式、位数和实际二进制路径；无需逐音源填写 DLL 路径。已可靠识别的 x64 候选可自动关联，也可选中后点击「使用选中版本」。包含可选独立 x86 宿主的版本也可自动关联 Sylenth1 x86 VST2，已有自定义外部渲染器会保留；未知候选和其他 x86 插件不会自动启用。
3. 已关联的 Vital 独立程序可使用原生方式。点击「采用 Vital 原生参数」匹配其固定力度与尾音比例。已有的有效版本选择会保留，自动扫描不会擅自替换用户配置的外部渲染器。
4. 「预览渲染器（高级）」中仍可独立设置外部渲染程序或具备宿主依赖的 Python，不等同于插件 DLL 路径。可选 DawDreamer 桥接为 x64，须匹配插件位数；本机旧运行库问题已修复，Serum 1.334 的一个实际 FXP 已生成并由用户确认三音区试听正常。依赖安装、自检与真实兼容边界见渲染记录，尚不代表批量验收。
5. 保存三音区 MIDI 音高、BPM、时长和存储预算，然后扫描预制目录并生成预览。默认跳过已有完整、有效预览，即使随后修改模板或插件配置；需要重新生成时，先勾选「强制全量生成」。该选项只作用于本次操作，重复副本不单独渲染。
6. 试听低、中、高三个音区。待确认预览须由用户核对对应关系后确认；静音与削波提示保留在详情中。

任务运行中可点击「停止」，立即结束当前渲染进程，已完成结果逐项保存。下次生成只继续未完成项。强制生成也不会预先清空旧音频；当前项停止或失败时保留其旧的有效预览，尚未处理项不变。

「已生成（含待确认）」筛选包含真实存在的预览文件，不只统计已确认项。Vital 原生输出默认标记「已生成待确认」：音频已经保存，可以试听，但仍须核对预制及外部资源。生成或复用后自动展示已生成项，并清除冲突的搜索、音源和收藏筛选；启动时会显示已保存预览数量，也可点击「查看已生成」。设置中的「当前音色库数据目录」可用于核对是否打开了同一套音色库。

点击生成后，音色库上方立即显示准备状态，随后显示当前音色、处理数量、总体百分比与用时。任务结束后保留生成、复用、失败和跳过原因汇总；未配置渲染器时不会显示为生成成功，可通过设置图标直接打开对应配置区域。安装目录中发现插件不等于已有可用的渲染宿主。大批量进度合并刷新，不逐项重新筛选整个音色库或写入运行记录。

支持 `.vital`、`.vitalbank`、`.fxp`、`.SerumPreset` 和 `.fxb` 的对应扫描规则。自动识别优先采用独有后缀和已核对的 VST 文件头；最近的目录名称可辅助区分 Serum 版本。已核对的文件头优先于误放的目录名称。未知文件头、版本冲突或缺少可靠依据的共享格式保留为「待识别」，不会进入渲染队列；可在详情中核对并手动指定音源，选择会随下次扫描保留。

识别依据与标签随索引保存，收藏和反馈不会因重新分类而丢失。音源发生变化时旧预览失效，需要重新生成。明确指定音源的目录优先于重叠的自动识别目录。识别文件归属不代表实际插件可加载或已通过兼容性验证。

扫描同时保存原文件 MD5 和 SHA256。相同 MD5、音源及包内位置的副本保留各自路径、ID、收藏与反馈，只选一个代表项显示和渲染；「显示重复项」可查看所有路径，搜索支持 MD5，「导出 MD5 索引」保存完整映射。原代表文件丢失时会提升可用副本，只有 SHA256 与有效音频映射也一致才复用旧预览，复用后仍需试听确认。不同银行内部条目不因共享包文件 MD5 而合并。

插件扫描只读取 PE、版本信息和必要的 VST 导出，不加载或执行插件。熟悉的文件名不足以识别产品；不相关 DLL 和 SerumFX 效果器不会作为已支持乐器关联。默认优先当前适配方式使用的格式，再选择较新的版本；VST3 被发现不代表当前宿主能渲染它。

Vital 从独立程序改选 VST 时会清除旧的原生程序并转为未配置，需要另外指定兼容宿主；改回独立程序时恢复原生方式并清除旧 VST 关联。

Vital 包仅索引内部条目；已识别但未实现渲染的银行显示「待适配」，不会伪造音色槽位或预览。手动指定银行所属音源也不会解除此限制。Serum 2 目前可索引，需另行实现真实适配器。

「外部工作进程」接受自定义本地渲染器，采用 JSON 请求、结果映射和适配器版本标记，详见 [进程协议](docs/rendering.md)。程序不会执行 shell 命令模板。

## 构建与验证

```powershell
dotnet restore SoundPreviewer.sln --configfile NuGet.Config
dotnet build SoundPreviewer.sln -c Release --no-restore
.\tests\SoundPreviewer.Tests\bin\Release\net8.0-windows\SoundPreviewer.Tests.exe
python -m unittest discover -s scripts/renderers -p test_dawdreamer_worker.py
dotnet publish src/SoundPreviewer.App/SoundPreviewer.App.csproj -c Release --no-restore -o artifacts/publish
```

可选 32 位 Sylenth1 宿主须另行运行 `pwsh -File src/SoundPreviewer.Vst2Host/build.ps1` 后再发布主应用；此项目单独使用官方 NuGet 依赖，基础解决方案不受影响。目标电脑需 x86 .NET 8 Desktop Runtime。真实单 FXP 已生成并播放，尚未代表批量或 FXB 验收。详见渲染记录。

测试覆盖实际 WAV 格式和异常值、SQLite 事务与 v1→v2 迁移、MD5 回填与重复代表提升、混合目录识别与冲突、手动分类和旧设置兼容、插件 PE / 导出 / 位数 / VST3 包与版本选择、扫描增量与反馈、音色包资源变化、未知音源禁止渲染、进程超时、停止后逐项恢复、默认复用与强制生成、原子提交和有限重试。测试中的声音、PE 文件和子进程仅用于基础设施验证，不能作为插件兼容性的证据。

默认运行 22 组无需音频设备的测试。可添加 `--test-playback`，在具备默认音频设备的 Windows 上进行第 23 组静音播放测试，检查暂停、跳转、继续和释放。测试同时覆盖即时阶段反馈、空队列、全部未配置、大批量汇总与准备阶段取消，以及宿主配置检查、x86 外部宿主边界和待确认音频的持久化复用。

UI 可用隔离音色库生成两种窗口尺寸、三个页面的截图并自动退出：

```powershell
.\src\SoundPreviewer.App\bin\Release\net8.0-windows\SoundPreviewer.exe --data-directory .\artifacts\ui-smoke --smoke-test
```

## 数据与维护

所有预制文件均只读。索引使用 Windows 自带的 `winsqlite3.dll`，旧数据库自动迁移并在下次可访问的扫描中回填 MD5；Vital 预览使用原生 PCM16，DawDreamer 桥接保留 float32 原始输出，先校验临时文件，再原子提交。试听通过 WinMM 输出内存中的 PCM16 音频，独立音量不修改预览文件，也不依赖 Windows Media Player。生成缓存包含音色内容、插件/程序指纹、实际版本、试听模板及适配器版本；默认复用依据已保存模板校验完整预览，不因当前配置变化自动重渲染。源文件内容或音源归属变化会使旧映射失效。单文件外部资源的变更跟踪仍需专用适配器补充。

不会自动下载模型或商业音源，不包含用户预制。可选 DawDreamer 及其他组件的发行许可需在正式打包前逐项核对。当前仅调用用户安装的音源；本仓库未替用户选定项目发行许可证。
