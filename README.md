# SoundPreviewer

把合成器音色生成短试听片段，在一个本地音色库里搜索、筛选和播放，减少逐个打开音源试音的时间。已有预览无需打开 DAW。

**当前版本：1.0.0** · 支持 Windows x64、macOS Apple Silicon / Intel。

## 软件功能

- 扫描混合音色目录，按音源、状态、来源、音色包、分类、标签和收藏组合筛选。
- 生成低、中、高三个音区的短预览，支持并行、内存预算、停止续做和相同内容共用缓存。
- 播放 WAV / AAC 预览，空格从头重播，也可单独试听中、高、低音区。
- 编辑分类名称与别名、个人标签、收藏和反馈；支持中英文界面与独立的分类标签语言。
- 数据和预览保存在本地，可备份、搬移、压缩已有 WAV，并复制完整生成结果反馈问题。

目前可生成 Vital、Serum 1、Serum 2 和 Sylenth1 的受支持音色；Spire 可扫描索引，原生预览生成尚未开放。音源插件、音色文件和授权需自行准备。

## 最小上手流程

1. **打开程序**：从 [GitHub Releases](https://github.com/Reguluz/SoundPreviewer/releases) 下载对应平台包。Windows 安装或完整解压后打开 `SoundPreviewer.exe`；Mac 将 `.app` 复制到可写的独立文件夹后打开。程序已含 .NET 运行库。
2. **最小配置**：点击「扫描音源」，在「音源与设置 → 已发现音源」选择正确版本并关联；到「预览生成」核对方式后保存。Vital 选择独立程序与「Vital 原生」；Serum 1 / 2 点击「一键准备生成环境」；Windows Sylenth1 x86 使用随包宿主。只配一个音源即可开始。
3. **扫描音色**：在「音源与设置 → 目录」添加音色文件夹，混合目录选择「自动识别」，然后点击「扫描音色」。首次使用会自动建立必要配置。
4. **测试一个音色**：选中一条「待生成」音色，在右侧点击「重新生成此音色」，试听中、高、低三个音区，与音源内的声音核对；需要时点击「确认预览对应此音色」。失败时先按详情提示修正，再重试这一条。
5. **日常使用**：搜索或勾选筛选条件，点击「生成 / 继续」处理当前结果；已有有效预览会跳过，「停止」保留已完成项。选中已有预览后按空格试听，再用收藏、标签和分类整理。

升级或搬移前退出程序，保留 **Preview、Config、categories.json、tags.json** 和自定义语言文件，以继续使用个人记录与缓存。
