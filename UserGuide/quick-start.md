目标：用一个音色完成生成和试听，再处理更多音色。先准备一个已授权、可以正常打开的受支持音源和它的音色文件；程序不附带商业音源或私人音色。

<a id="launch"></a>

## 1. 打开程序

从项目发布页下载对应平台包。Windows 安装后打开，或将免安装包**完整解压**后打开 `SoundPreviewer.exe`；Mac 将 `.app` 复制到有写入权限的独立文件夹后打开。第一次运行会建立必要配置，不必先复制 Preview 或 Config。详细平台要求见[安装与启动](installation.md)。

<a id="configure"></a>

## 2. 最小配置：只配置一个音源

1. 点击顶部 **「扫描音源」**。
2. 打开 **「音源与设置 → 已发现音源」**，选正确版本，点击「使用选中版本」。扫描不到时，到「目录」添加音源安装目录，再扫描。
3. 打开 **「预览生成」**，按下表配置一种生成方式，核对关联插件，再点击 **「保存设置」**。其他音源可以暂不配置。

| 准备的音源 | 最少需要做什么 |
| --- | --- |
| Vital | 选择 Vital **独立程序**，方式为「Vital 原生」；先用独立 `.vital` 测试 |
| Serum 1 / Serum 2 | 关联对应 VST2 / VST3 插件，点击「一键准备生成环境」；首次联网完成后保存 |
| Windows Sylenth1 x86 | 关联 x86 插件并使用随包宿主；缺少 x86 运行库时按提示安装 |

其余架构与格式限制见[音源与生成环境](synths.md#support)。保留默认试听模板、自动并行和 4 GiB 内存预算即可开始。

<a id="scan"></a>

## 3. 添加音色目录并扫描

在 **「音源与设置 → 目录」** 添加一个音色文件夹，混合目录选择「自动识别（混合音色包）」，点击顶部 **「扫描音色」**。返回「音色库」，找到一条状态为「待生成」的受支持音色。

若显示「无法预览」，先查看右侧原因；FXB 银行和 Spire 原生格式目前不能直接生成。可先选择独立 `.vital`、Serum 1 `.fxp`、Serum 2 `.SerumPreset` 或 Sylenth1 `.fxp`。

<a id="test"></a>

## 4. 测试：只生成一个音色

选中该音色，在右侧详情点击 **「重新生成此音色」**，等待状态变为「已生成」。在底部试听「中 / 高 / 低」三个音区，并与音源中直接打开的声音核对。需要确认时，点击「确认预览对应此音色」。

**通过标准：** 能听到预期音色，三个音区与目标对应，详情没有加载失败提示。失败时先按[故障排查](troubleshooting.md)修正原因，再重试这个音色。

<a id="use"></a>

## 5. 使用：筛选、批量生成、随时试听

搜索或勾选音源、分类等条件，点击 **「生成 / 继续」**。它只处理**当前搜索与筛选结果**，已有有效预览会跳过；处理全库前先清空筛选。点击「停止」保留已完成预览，下次可以继续。

选中已有预览后，按 **空格** 从头播放；播放中再按空格可重播。搜索等文本框内的空格仍用于输入。收藏、标签与分类见[音色库整理](library.md)，模板和进度含义见[生成与试听](rendering.md)。

使用后退出程序，备份程序旁的 Preview、Config、categories.json、tags.json 与自定义语言文件。具体步骤见[备份与升级](storage.md#backup)。

<a id="faq"></a>

## 常规问题 Q&A：有没有这项功能？

| 问题 | 回答与操作入口 |
| --- | --- |
| 可以选择预览音高吗？ | **可以。** 在「音源与设置 → 试听与存储」分别填写低、中、高音，例如 `C2`、`C4`、`C6`，也支持 `C#4` / `Db4`。保存后用于新生成的预览；已有预览需点击「重新生成此音色」才会换用新模板。播放时可单独点「中 / 高 / 低」。见[试听模板](rendering.md#template)。 |
| 可以调整预览时长吗？ | **可以。** 快速预览可设每音区 0.1–4 秒；关闭快速预览后可调整按键时长与尾音。Vital 原生方式有参数限制，见[试听模板](rendering.md#template)。 |
| 可以自定义标签吗？ | **可以。** 选中音色，点击「编辑标签与分类 → 新增标签」，可填写名称和别名，再勾选并保存。标签默认无内容，可记录情绪、用途等；重新扫描不会覆盖手工选择。见[分类、标签与收藏](library.md#metadata)。 |
| 可以自定义分类、收藏音色吗？ | **可以。** 同一编辑区可新增分类、修改名称和别名；详情区可收藏或记录喜欢 / 不喜欢反馈。需要时可「恢复自动」分类。见[音色库整理](library.md#metadata)。 |
| 可以组合筛选、一次选择多个标签吗？ | **可以。** 每组可直接多选，无需按 Ctrl / Shift；同组满足任意选中项，不同组同时满足。批量生成只处理当前搜索与筛选结果。见[搜索与多选筛选](library.md#filters)。 |
| 批量生成可以停止后继续吗？重复音色会重复生成吗？ | **可以停止续做。** 点击「停止」保留已完成项，下次「生成 / 继续」跳过已有有效预览；相同内容的副本共用有效缓存。见[队列进度与停止](rendering.md#progress)。 |
| 不打开 DAW 和音源、断网时也可以播放吗？ | **已有有效预览可以本地播放。** 生成新预览仍需相应音源及授权；一键准备生成环境首次需要联网。见[安装与启动](installation.md)和[生成环境](synths.md#environment)。 |
| 可以选 WAV / AAC，或者压缩旧预览吗？ | **可以。** 在「试听与存储」选择保存格式，也可「压缩已有 WAV」以释放空间；已有有效预览不会因切换格式而强制重做。见[压缩与保存格式](storage.md#compression)。 |
| 可以切换英文界面、单独选择标签语言吗？ | **可以。** 内置简体中文和英语；「界面语言」与「分类与标签语言」可独立选择，也可添加语言 JSON。见[语言与外观](appearance.md#language)。 |
| 可以直接预览 Spire 或 FXB 银行吗？ | **目前不能直接生成。** Spire 原生格式和 FXB 可扫描索引；FXB 请先在音源中导出独立音色。Vital `.vitalbank` 中通过资源检查的条目可以生成，详见[格式支持表](synths.md#support)。 |
| 可以一键把音色加载到 DAW 轨道吗？ | **目前不能自动建轨或加载。** 可以「复制文件地址」或「定位音色文件」，然后在 DAW 中通过对应音源加载原文件。见[定位、复制文件地址与 DAW](library.md#daw)。 |

遇到报错、扫描不到音源或生成声音不符时，请转到[常见问题与故障排查](troubleshooting.md)。
